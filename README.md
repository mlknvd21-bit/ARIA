# ARIA — Advanced Reasoning & Intelligence Assistant

**Created by Malik Naveed (Pakistan)**  
*Your personal AI assistant on Termux for Android.*

[![License: MIT](https://img.shields.io/badge/License-MIT-green.svg)](LICENSE)

## ✨ Key Features
- 🧠 ReAct reasoning + Tool use
- 🤖 Multi-Agent Swarm
- 📱 Android integration (SMS, notifications, camera, WiFi, GPS)
- 📖 Offline Quran & Hadith (Arabic, Urdu, English)
- 📦 Plugin system (electronics, weather, etc.)
- 💾 Backup & Restore with diff
- 🎤 Voice (speech-to-text, text-to-speech)
- 🕸️ Web GUI

## 📥 Installation (Termux)
git clone https://github.com/mlknvd21-bit/ARIA.git
cd ARIA
pip install -r requirements.txt

## ▶️ Usage
python main.py        # CLI mode
python main.py --web  # Web GUI → http://localhost:8000
